# UPGRADER ready build

Что сделано:

- Расстановка как на скрине: верхняя панель, слева LIVE-DROPS, центр с апгрейдом, снизу магазин и список целей.
- Магазин с покупкой скинов за баланс.
- Инвентарь пользователя.
- Правый список целей зависит от цены выбранного предмета: показываются только скины дороже.
- Шанс апгрейда считается автоматически: `мой предмет / целевой предмет * 100`, максимум 75%.
- LIVE-DROPS сохраняет успешные апгрейды.
- Наведение на LIVE-DROP показывает ник и шанс через title.
- Клик по LIVE-DROP открывает профиль игрока.
- Админ-панель позволяет выдавать баланс и предметы.
- Firebase rules дают админу право выдавать предметы игрокам.

## Важно

В `js/firebase-config.js` проверь `appId`. Я оставил твой Firebase project config из переписки, но `appId` лучше скопировать точный из Firebase Console.

## Как сделать себя админом

В Realtime Database вручную поставь:

```json
users/YOUR_UID/role = "admin"
```

После этого появится кнопка ⚙ в верхней панели.

## Запуск

Открой `index.html` через локальный сервер, например:

```bash
npx serve .
```

Или деплой:

```bash
firebase deploy
```
