# UPGRADER ready build — no CSFloat / no Blaze

Этот вариант не использует CSFloat API и не требует Firebase Blaze.

Что сделано:

- Расстановка как на скрине: верхняя панель, слева LIVE-DROPS, центр с апгрейдом, снизу магазин и список целей.
- Магазин с покупкой скинов за баланс.
- Инвентарь пользователя.
- Правый список целей зависит от цены выбранного предмета: показываются только скины дороже.
- Шанс апгрейда считается автоматически: `мой предмет / целевой предмет * 100`, максимум 75%.
- Колесо не крутится, крутится только стрелка.
- Жёлтый сектор колеса меняется от шанса успеха.
- LIVE-DROPS сохраняет успешные апгрейды.
- Наведение на LIVE-DROP показывает ник и шанс через title.
- Клик по LIVE-DROP открывает профиль игрока.
- Админ-панель позволяет выдавать баланс и предметы.
- В профиле можно продать один скин или сразу все скины.
- Продажа скинов возвращает 100% цены предмета.
- Скины загружаются из `qwkdev/csapi`, а цены сайт выставляет сам по встроенной формуле.
- Если GitHub/CDN недоступен, используется встроенный fallback-каталог с уже заданными ценами.

## Где менять цены

Цены задаются в файле:

```txt
js/items.js
```

Главные места:

```js
const RARITY_PRICE = {
  common: 120,
  blue: 350,
  purple: 1200,
  pink: 3500,
  red: 10000,
  gold: 25000
};
```

И функция:

```js
function syntheticPrice(item) { ... }
```

Для конкретных предметов можно вручную менять `price` в `FALLBACK_SKINS`.

## Важно

В `js/firebase-config.js` проверь `appId`. Его лучше скопировать точный из Firebase Console.

## Как сделать себя админом

В Realtime Database вручную поставь:

```json
users/YOUR_UID/role = "admin"
```

После этого появится кнопка ⚙ в верхней панели.

## Запуск

Открой `index.html` через локальный сервер, например:

```bash
npx serve .
```

Или деплой без Blaze:

```bash
firebase deploy --only hosting,database
```
